# Minerva_Chess

## Rating/Strength
The approximated chess rating for this chess engine is 2600 elo, according to analysis by (Strategic Test Suite)[https://github.com/fsmosca/STS-Rating].

## Credits
This chess engine is heavily inspired by [Bit Board Chess](https://github.com/maksimKorzh/bbc). In my opinion, it's the most easily understandable high-level chess engine.
It uses NNUE evaluation that is developed and trained by [StockFish](https://github.com/official-stockfish/Stockfish).
